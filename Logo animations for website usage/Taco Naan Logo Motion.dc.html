How to use it
Sizes
Header 34–56px tall · Hero 260–520px wide · Footer 120px wide · Never below 120px wide, the fine rules in the sunburst break up. For a 32px favicon, crop to the seal only — the ribbon is unreadable at that size.
Grounds
Ink artwork on #f0ece3 / #f7f4ee / white. White artwork on #14120f or a photo with a dark scrim over it. Clear space on all four sides = half the ribbon's height. Nothing else inside that box.
Motion rules
One reveal per page load, never looping. Everything under 1.25s. Honour prefers-reduced-motion. Gate the splash stamp behind sessionStorage so repeat visitors skip it.
Drop-in code
Paste the CSS once in your global sheet, point the two url() paths at your hosted file, and use the markup anywhere.
@keyframes logo-stamp {
  0%   { opacity:0; transform:scale(1.55) rotate(-7deg); filter:blur(16px) }
  55%  { opacity:1; transform:scale(.955) rotate(1.4deg); filter:blur(0) }
  74%  { transform:scale(1.028) rotate(-.5deg) }
  100% { transform:scale(1) rotate(0) }
}
@keyframes logo-rise  { from { opacity:0; transform:translateY(24px) } }
@keyframes logo-sheen {
  0%   { background-position:190% 0; opacity:0 }
  12%, 88% { opacity:1 }
  100% { background-position:-130% 0; opacity:0 }
}

.logo        { display:block; height:auto; }
.logo--hero  { width:clamp(260px,34vw,520px);
               animation:logo-stamp 1.15s cubic-bezier(.16,1,.3,1) both; }
.logo--head  { height:54px; width:auto;
               animation:logo-rise .8s cubic-bezier(.16,1,.3,1) both;
               transition:height .3s cubic-bezier(.16,1,.3,1); }
.is-scrolled .logo--head { height:34px; }

/* masked sheen — lights up the mark only, not its box */
.logo-link   { position:relative; display:inline-block; line-height:0; }
.logo-link::after {
  content:""; position:absolute; inset:0; pointer-events:none; opacity:0;
  mask:url(/img/taco-naan.png) center/contain no-repeat;
  -webkit-mask:url(/img/taco-naan.png) center/contain no-repeat;
  background:linear-gradient(100deg,transparent 36%,rgba(255,255,255,.95) 50%,transparent 64%);
  background-size:260% 100%; background-repeat:no-repeat;
}
.logo-link:hover::after { animation:logo-sheen 1s ease-out; }

@media (prefers-reduced-motion:reduce) {
  .logo, .logo-link::after { animation:none !important; opacity:1; transform:none; }
}

Do
Get the badge redrawn as an SVG before launch — it's line art and will stay crisp at every size, and the sheen mask works the same way.
Ship width/height on the img so the reveal doesn't shift your layout.
Keep the header lockup to one animation: rise in, sheen on hover.
Don't
No looping spin, no bounce on scroll, no animation on the footer mark.
Don't recolour, stretch, add a drop shadow, or rotate the resting state.
Don't stack the stamp and the sheen on the same element at load — pick one entrance.
